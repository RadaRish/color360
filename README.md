# Color360 — demo site

This repository contains a minimal prototype for the main landing page of Color360
(frontend + a tiny Node.js/Express backend to demo registration/login/demo token).

## What's included
- `index.html` — landing page with "Перейти в приложение", news, about, contacts.
- `assets/` — styles and client JS (simple fetch calls to API).
- `server.js` — minimal backend with endpoints:
  - `POST /api/register` — {name,email,password}
  - `POST /api/login` — {email,password}
  - `POST /api/demo` — returns demo token
  - `GET /api/news` — sample news list
- `package.json` — dependencies

## Run locally
1. Install Node.js (v16+ recommended).
2. Unzip the archive and in the project folder run:
   ```
   npm install
   node server.js
   ```
3. Open http://localhost:3000 in your browser.

### HTTPS / Mixed Content

Если вы запускаете редактор за обратным прокси с включённым HTTPS, убедитесь, что:
1. Все внешние API вызываются через относительные пути (`/api/...`) или через `https://`.
2. В `pano/ui/url_normalizer.js` включена автоматическая переконвертация `http://` → `https://` для защиты от Mixed Content.
3. При необходимости можно задать `window.__API_ORIGIN` до загрузки `main.js`, чтобы форсировать конкретный backend origin.

## 🧩 Автоисправление ретуши (RetouchManager / LaMa)

В репозиторий добавлен скрипт `fix-retouch-auto.sh`, который автоматизирует обновление `retouch_manager.js` до последней версии с:

- FastMask fallback (ускоренное построение маски без тяжёлого UV)
- Переключением основного API на `/api/lama/inpaint` с fallback `/api/retouch`
- Диагностическими логами (⏱️ тайминги, предупреждения зависаний)
- Принудительным cache-bust HTML и опциональной инъекцией `force-retouch.js`

### Запуск на сервере

```bash
curl -fsSL https://raw.githubusercontent.com/RadaRish/color360/main/fix-retouch-auto.sh -o fix-retouch-auto.sh
sudo bash fix-retouch-auto.sh
```

Автоматически без вопросов:

```bash
sudo AUTO_Y=1 bash fix-retouch-auto.sh
```

Указать вручную веб-корень:

```bash
sudo WEB_ROOT=/var/www/html AUTO_Y=1 bash fix-retouch-auto.sh
```

После запуска зайдите в браузере на `/pano/?v=TIMESTAMP`, сделайте Ctrl+F5 и проверьте в Console наличие:
- `⚡ FastMask:`
- `🎨 Debug RetouchManager: отправляем запрос на /api/lama/inpaint`

Откат:

```bash
ls -1d retouch_backup_* | tail -n 1
cp retouch_backup_YYYYMMDD-HHMMSS/var/www/html/path/to/retouch_manager.js /var/www/html/path/to/retouch_manager.js
```

При отсутствии прямого подключения JS — создаётся `force-retouch.js` и инжектируется в первый найденный `index.html`.
