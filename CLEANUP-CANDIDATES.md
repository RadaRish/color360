# Кандидаты на удаление (22.10.2025)

Ниже список файлов/папок, которые не используются в продакшене и подлежат удалению как устаревшие: бэкапы, патчи, тестовые скрипты.

Будет безопасно полностью удалить их из репозитория. По умолчанию скрипт `scripts/cleanup-remove-legacy.ps1` перемещает их в архив `archive/2025-10-22/` (для отката), а затем можно удалить архив после проверки.

## Файлы и папки

- pano/backup/scene_list.js — резервная копия UI сцены (устаревшее)
- pano/backup/retouch_manager.js — резервная копия менеджера ретуши (устаревшее)
- pano/backup/hotspot-editor.js — резервная копия редактора хотспотов (устаревшее)
- patch-full-retouch-changes.diff — служебный патч, не нужен в рантайме
- patch-retouch_manager.diff — служебный патч, не нужен в рантайме
- test-syntax.sh — тестовый скрипт
- test-lama-access.sh — тестовый скрипт
- scripts/smoke-test-retouch.sh — тестовый скрипт

## Примечания
- В кодовой базе нет ссылок на эти файлы (проверено grep).
- Если есть возражения по любому пункту — отметьте его в PR и мы оставим файл.

## Как запустить очистку (Windows PowerShell)

1. Откройте PowerShell из корня репозитория.
2. Выполните:

```powershell
# Переместить кандидаты в архив (по умолчанию)
./scripts/cleanup-remove-legacy.ps1 -Mode Archive

# Или удалить полностью без архивации (безвозвратно)
./scripts/cleanup-remove-legacy.ps1 -Mode Delete
```

После проверки архив можно удалить вручную, либо запустить скрипт повторно с `-Mode Delete` по архивному пути.
