# Инструкция по управлению триальной (бесплатной) версией

## Обзор

В редакторе панорамных туров реализована система управления функциями для триальной (бесплатной) и премиум (платной) версий. Это позволяет легко переключаться между версиями, изменяя только один конфигурационный файл.

## Файл конфигурации

Основной файл конфигурации: `pano/config/trial_features.js`

## Текущие ограничения триальной версии

### 1. Скрытые кнопки в панели управления
- ❌ Полный экран
- ❌ Очистить вид камеры для сцены
- ❌ Удалить объект (ретушь)
- ❌ Отменить последнюю ретушь

### 2. Скрытые элементы интерфейса
- ❌ Иконка пользователя (аватар)
- ❌ Контекстное меню по правому клику мыши на сцене

### 3. Добавленные кнопки
- ✅ Кнопка "Добавить хотспот" в левой панели
- ✅ Кнопка "Добавить инфоточку" в левой панели

### 4. Ограничения в настройках хотспотов
- ❌ Выбор собственной иконки (опция "🖼️ Собственная иконка" скрыта)
- Доступны только стандартные иконки:
  - 🔺 Переход между сценами
  - ℹ️ Инфоточка

### 5. Ограничения на количество символов
- **Название хотспота/инфоточки**: максимум 25 символов
- **Описание**: максимум 250 символов
- **Автоматический перенос строк**: каждые 36 символов в описании

## Как переключить на премиум версию

Откройте файл `pano/config/trial_features.js` и измените следующие параметры:

```javascript
export const TRIAL_CONFIG = {
  // Установите false для активации премиум версии
  isTrialVersion: false,

  // Включите все кнопки в панели управления
  toolbar: {
    fullscreen: true,           // Полный экран
    clearCameraView: true,       // Очистить вид камеры
    retouchObject: true,         // Ретушь
    retouchUndo: true,           // Отменить ретушь
    saveProject: true,
    exportProject: true,
    setCameraView: true,
    settings: true
  },

  // Включите элементы интерфейса
  ui: {
    userAvatar: true,            // Иконка пользователя
    contextMenu: true            // Контекстное меню
  },

  // Разрешите все функции маркеров
  markers: {
    customIcon: true,            // Собственная иконка
    
    limits: {
      titleMaxLength: 100,       // Увеличенный лимит
      descriptionMaxLength: 1000, // Увеличенный лимит
      descriptionLineMaxLength: 100 // Увеличенный лимит
    }
  },

  // Кнопки создания маркеров (можно оставить или скрыть)
  markerButtons: {
    addHotspot: false,           // Не нужны, т.к. есть контекстное меню
    addInfoPoint: false
  }
};
```

## Важные замечания

1. **CSS классы**: Элементы с классом `trial-hidden` автоматически скрываются через CSS. Изменение конфигурации не требует изменения HTML.

2. **Контекстное меню**: В триальной версии правый клик на сцене отключен. В премиум версии появляется меню с опциями создания маркеров.

3. **Иконки маркеров**: В HTML опция "Собственная иконка" скрыта через класс `trial-hidden` в триальной версии.

4. **Обновление после изменений**: После изменения конфигурации просто обновите страницу в браузере (F5 или Ctrl+R).

## Структура файлов

```
pano/
├── config/
│   └── trial_features.js      # Конфигурация версий
├── core/
│   └── viewer_manager.js      # Использует конфигурацию для контекстного меню
├── ui/
│   └── hotspot-editor.js      # Использует конфигурацию для ограничений
├── main.js                    # Обработчики кнопок маркеров
└── index.html                 # HTML с классами trial-hidden
```

## Будущие возможности

При необходимости можно легко добавить:
- Проверку подписки пользователя через API
- Динамическое переключение версий без перезагрузки
- Уведомления о премиум функциях
- Интеграцию с системой платежей

## Техническая поддержка

Для переключения между версиями достаточно изменить один файл: `pano/config/trial_features.js`

Все остальные изменения применятся автоматически при загрузке редактора.
