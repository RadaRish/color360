# Документация

Этот каталог собирает все инструкции и справочные материалы из корня репозитория.

## Как устроено
- `docs/` — актуальная документация.
- `docs/legacy/` — материалы, которые считаются устаревшими или дублями; сохраняются для справки.

## Куда что перенести (рекомендации)
Следующие файлы из корня целесообразно переместить в `docs/`:
- DEPLOYMENT.md
- DEPLOYMENT-PRODUCTION.md
- PRODUCTION-INSTALL-GUIDE.md
- LAMA-SETUP.md
- AI-SETUP-GUIDE.md
- ARROW_ICON_CHANGES.md
- TRIAL-VERSION-GUIDE.md

В `docs/legacy/` (как устаревшие/избыточные версии):
- INSTALL-RU.md
- INSTALL-REG-RU.md
- INSTALL-UPDATE-GUIDE.md
- LAMA-SETUP-GUIDE.md
- FAQ-UPDATE.md

Из каталога `pano/`:
- `pano/INSTALL.md` → `docs/`
- `pano/DEPLOY.md` → `docs/`
- `pano/ARCHITECTURE_PLAN.md` → `docs/`

Перемещения обратимы. При необходимости можно вернуть файлы обратно.
